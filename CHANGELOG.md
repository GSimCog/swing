## [1.0.0-beta] — 2025-04-27
### Added
- First public beta release of SWING 🎉
- Admin interface for manual country data editing and approval
- User/admin authentication and access control
- OpenAI integration for AI-powered answer generation and validation
- DBpedia and Wikidata synchronization for semantic data updates
- Dynamic quiz generation with multiple blank types
- Detailed debug logs for backend operations
- Permissions: only admins can approve/edit sensitive data
- Real-time feedback and logs for admin operations
- Secure leaderboard and user ranking
- Fully documented codebase (in Portuguese)

### Changed
- Improved error handling and consistent JSON responses from backend
- Enhanced admin tools for batch updates and AI suggestion propagation

### Known Issues
- SQLite database (not recommended for heavy concurrent usage)
- Some error messages are only in English
- Basic admin UI (UX improvements planned)
