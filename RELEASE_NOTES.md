# 🎉 Version 1.0.0-beta — First Public Beta

This is the first **beta** release of the **SWInG** project! The system is now stable and ready for community testing. We invite developers and contributors to test, report bugs, and suggest improvements.

---

## 🆕 Main features

- **Manual country data editing:** Admin interface for directly editing and approving country information via the web.
- **Authentication flow:** User/admin access control.
- **OpenAI integration:** AI-powered answers for filling in blanks.
- **DBpedia and Wikidata sync:** Fetch and update semantic data from external sources.
# 📝 Release notes

## 🎉 Highlights

- **Quiz system:** Dynamic quiz generation with multiple blank types.
- **Detailed debug logs:** Easier problem identification during usage.
- **Validations and permissions:** Only admins can approve/edit sensitive data.

---

## 🐞 What to test

- Manual editing of country blanks via the web interface.
- Approving and rejecting AI suggestions.
- Login/logout flow and access permissions.
- Automatic data updates via AI and external sources.
- Quiz viewing and functionality.

---

## ⚠️ Known limitations

- Database uses SQLite (not recommended for heavy concurrent usage).
- Some error messages are still in English only.
- Basic admin interface (UX improvements planned for future versions).

---

## 💡 How to contribute/test

1. Fork the repository and clone it locally.
2. Follow the README instructions for installation and setup.
3. Test the main flows and report bugs using the **Issues** tab on GitHub.
4. Suggestions and improvements are welcome!
