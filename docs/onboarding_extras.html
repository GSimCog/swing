3. Exemplo de quiz.config

[settings]
database = WIKIDATA
openai_api_key = SUA_CHAVE_OPENAI
ai_confidence_threshold = 90
dbpedia_sparql_query = https://dbpedia.org/sparql
wikidata_sparql_query = https://query.wikidata.org/sparql
  • database: Fonte principal de dados (WIKIDATA ou DBPEDIA).
  • openai_api_key: Chave de API para acesso ao modelo generativo.
  • ai_confidence_threshold: Score mínimo para aprovação automática de sugestões da IA.
  • dbpedia_sparql_query, wikidata_sparql_query: Endpoints SPARQL das fontes externas.

4. Setup do Ambiente

  1. Clone o repositório e acesse a pasta quiz_v3.
  2. Crie e ative um ambiente virtual Python:
    python -m venv .venv
    source .venv/bin/activate # Linux/Mac
    .venv\Scripts\activate # Windows
  3. Instale as dependências:
    pip install -r requirements.txt
  4. Configure o arquivo quiz.config conforme o exemplo acima.
  5. Execute o app:
    python app.py

Para rodar rotinas batch de atualização, execute:
python -c "from data_update import update_reported_questions_with_ai; update_reported_questions_with_ai()"

6. Troubleshooting e Dicas

  • Verifique se o arquivo quiz.config está corretamente preenchido e acessível.
  • Erros de banco de dados geralmente indicam falta de permissões ou problemas de conexão SQLite.
  • Para logs detalhados, rode o app com debug=True em app.py.
  • Se a integração com OpenAI falhar, revise a chave openai_api_key e conexão de internet.
  • Para dúvidas sobre os modelos de dados, consulte a documentação técnica HTML principal.
