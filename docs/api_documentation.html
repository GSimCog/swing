app.py

Visão Geral

  • Inicialização do app Flask, banco de dados, autenticação e principais dependências.
  • Define modelos de dados, rotas de quiz, login, administração e histórico.
  • Integração com fontes externas (Wikidata/DBpedia) e IA (OpenAI) para preenchimento automático de dados faltantes.
  • Implementa lógica de confiança da IA (ai_confidence_threshold): respostas da IA com confiança >= threshold são propagadas diretamente; abaixo disso, vão para revisão manual (ReportedQuestions).

Principais Modelos

User
Modelo de usuário do sistema. Campos: id, username, password, email, score, timestamp.
ReportedQuestion
Modelo para perguntas reportadas ou sugestões da IA para revisão manual. Entradas criadas quando a confiança da IA é menor que o threshold.
CountryQuiz
Modelo para dados de quiz de países. Campos: id, country_label, data, timestamp.
CountryBlanksFromSemanticDatabase
Gerencia lacunas (blanks) nos dados de países, preenchidas via IA ou manualmente. Se ai_confidence >= threshold, pode ser aprovado automaticamente.
CountryQuizUpdatesHistory
Histórico de atualizações dos quizzes de países. Campos: id, function_name, country_label, key, old_data, new_data, ai_confidence, timestamp.

Principais Rotas e Funções

  • admin_tools: Painel administrativo para histórico, aprovação de sugestões, atualizações batch e logs em tempo real.
  • quiz: Rota do quiz. Gera perguntas, avalia respostas, registra erros/reportes.
  • approve_question / bypass_question: Aprovação manual/admin de sugestões da IA ou de usuários.
  • country_updates / approve_country_update: Gestão e aprovação de atualizações de dados de países.
  • request_or_load_country_data: Carrega dados do banco ou fontes externas.
  • login / register / logout: Autenticação de usuários.
  • Histórico administrativo: Todas as alterações relevantes são registradas para auditoria.

data_update.py

Visão Geral

  • Atualiza e gerencia dados do quiz de países, integrando IA generativa (OpenAI) e bancos de dados semânticos (DBpedia, Wikidata).
  • Implementa lógica de confiança da IA (ai_confidence_threshold): respostas da IA com confiança >= threshold são aprovadas e propagadas automaticamente; abaixo disso, vão para revisão manual/admin.
  • Atualiza perguntas reportadas, blanks de países, sincroniza dados do quiz, gera histórico de alterações e arquivos CSV para auditoria/admin.
  • Diferencia fluxos automáticos e manuais, com logging detalhado e integração com modelos de dados do app.
  • Todas as docstrings seguem padrão Google para facilitar manutenção e colaboração.

Principais Funções

determine_prompt(question_text)
Retorna o prompt adequado para uma pergunta sobre país, com base em palavras-chave identificadas no texto.
parse_ai_response(ai_response)
Extrai o valor e o score de confiança de uma resposta da IA no formato valor|confiança. Fundamental para o fluxo de aprovação automática/manual.
update_reported_questions_with_ai()
Atualiza perguntas reportadas sem resposta da IA, consultando o modelo generativo e salvando o resultado. Aprova automaticamente se confiança >= threshold.
update_country_blanks_from_semanticdatabase_with_ai()
Atualiza blanks de países utilizando IA. Aprova automaticamente se confiança >= threshold, senão envia para revisão manual.
update_countryQuiz_from_approved_questions()
Propaga respostas aprovadas de perguntas reportadas para o banco principal do quiz. Aprovação manual/admin é permitida independentemente da confiança.
update_countryQuiz_from_approved_blanks()
Propaga respostas aprovadas de blanks de países para o banco principal do quiz. Diferencia origem manual e IA para auditoria.
update_new_country_data_from_semanticdatabase_in_countryQuiz()
Sincroniza o quiz com novos dados de países obtidos de fontes externas. Adiciona, atualiza e remove países conforme necessário, registrando histórico.
generate_csv_from_country_blanks_of_semanticdatabase()
Gera arquivo CSV contendo respostas da IA para blanks de países, para auditoria externa.

Observações Gerais

  • Utiliza SQLAlchemy para manipulação do banco de dados SQLite.
  • Score de confiança da IA é fundamental para decidir se uma sugestão é aprovada automaticamente ou encaminhada para revisão manual/admin.
  • Todas as operações relevantes são logadas e, quando aplicável, registradas em histórico para auditoria.
  • Pode ser executado standalone para rotinas batch, mas normalmente é importado e chamado pelo backend Flask principal.
